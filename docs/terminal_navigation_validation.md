# 终端导航与研究页签验证记录

## 当前改造

公开研究终端在顶部提供可见的“返回首页”入口，并将首期股票池改为标题式研究页签。每个页签显示股票名称、代码、板块及可用的涨跌幅；活动页签使用金色边框与底色区分。窄屏下保留返回首页按钮，页签容器可横向滚动，不再显示原有侧栏股票列表。

## 本地浏览器验收

桌面视口下，火炬电子页签可切换主研究区，且返回首页按钮位于终端左上角。375px 移动视口下，顶部导航和页签均未发生横向挤压；“研究标的”标签为节省空间而视觉隐藏，因此端到端脚本改用页签的 ARIA role 与“中国卫星”内容来识别已加载状态，而不依赖该隐藏文案。

生产 Workers 地址已完成同样的桌面与移动端验收：公开终端加载成功，点击“火炬电子”页签后主标题更新为 `火炬电子 603678.SH`，点击“返回首页”后回到品牌首页；公开 tRPC 请求均返回 200，未发现浏览器控制台或网络错误。

随后在已连接浏览器直接访问 Workers 生产终端：初始加载态结束后，页面显示“返回首页”、5 个股票研究页签及中国卫星的公开行情、指数、评分和资金模块。这再次确认终端无需注册即可使用；注册仅用于收藏工作台。

在重新打开该生产路径后的第二次真实浏览器核验中，页面同样先显示数据连接状态，随后自动进入已加载数据页并展示相同的 5 个页签与公开研究模块。这说明加载态是公开行情初始化过程，而不是登录拦截或终端不可访问。
