# 财经新闻源核验记录

核验时间：2026-08-18。

## 公开可追溯候选来源

中国新闻网官方 RSS 页面：<https://www.chinanews.com/rss/>。页面公开列出了财经新闻 RSS 订阅地址：<https://www.chinanews.com.cn/rss/finance.xml>。该来源可作为财经新闻滚动播报的公开入口，播报项需要保留原始链接、来源名称和发布时间，不应改写成未经核验的判断。

新浪财经 RSS 页面：<https://rss.sina.com.cn/finance/>。页面提供财经新闻 RSS 频道与 OPML 入口，可作为备选公开新闻源；接入前需在运行环境中实际检查响应状态与 XML 字段。

东方财富财经频道：<https://finance.eastmoney.com/>。该页面提供财经资讯入口，但当前检索未确认稳定、无需认证的公开新闻 API，因此更适合作为用户点击查看的来源入口，而不是直接假设存在可长期依赖的接口。

上交所官网：<https://www.sse.com.cn/>。用于原始披露与交易所公告链接，适合在市场情绪摘要中作为来源说明；情绪摘要不得把媒体标题或未经核验的舆情推断成投资结论。

## 设计和口径约束

新闻滚动模块必须展示来源、发布时间、原始链接和最后刷新时间；源不可用时显示“公开新闻源暂不可用”，不得用虚构新闻、虚构标题或随机数据填充。市场情绪只基于可解释的公开指数与首期股票池横截面数据，展示“偏强情绪”“区间震荡”或“审慎观望”等观察标签，不预测收益、不构成投资建议。
