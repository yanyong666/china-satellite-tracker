# leek.fund 公开视觉参考记录

参考来源：<https://leek.fund/>。本记录只保存公开页面可见的设计观察，不复制其品牌内容、代码或素材。

## 公开页面观察

leek.fund 的首页标题为“LeekFund | 在编辑器中追踪行情”，整体采用深色近黑背景、绿色荧光强调色、细密网格和轻量光晕。顶部导航以“功能介绍、产品文档、更新日志、控制台”为主要入口，首屏使用大字号产品标题、短副标题、产品入口按钮和较多留白，整体更像一个面向开发者的产品官网，而不是传统证券行情页面。

其公开内容突出“零切屏”“状态栏股票配置”“资产管理”“个股异动”“板块行情”“大盘云图”“数据中心”等产品能力，并使用编辑器生态、状态栏、侧边栏和底部面板作为产品化叙事。页面视觉重点不是高密度表格，而是通过暗色工作台、绿色信号、网格背景、模块化能力卡片和动态行情预览建立沉浸式终端感。

## 华夏项目的设计转译边界

本项目仅借鉴深色工作台、绿色信号、数据网格、产品化能力叙事和行情预览的视觉语言，不复制 leek.fund 的品牌名称、文案、图形资产、页面代码或独特产品结构。华夏项目继续保留公开数据来源、透明评分、北向资金“盘中净流入未公开披露”口径、筹码峰不展示推算值、会员中心和“所有数据均来自公开披露，不构成投资建议”免责声明。
