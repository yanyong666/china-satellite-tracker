# 品牌标题页：设计依据与非复制性转译

## 参考范围

本次仅观察了用户提供的 [zhangting.us](https://www.zhangting.us/) 首页中**未受保护、公开可见**的首屏框架。该页面的主体文章内容在访问时被标注为受保护，因此没有提取、复用或改写其文章标题、品牌标识、图片、会员内容或其他受保护材料。

| 可公开观察到的设计特征 | 华夏标题页的转译方式 | 明确未采用的内容 |
| --- | --- | --- |
| 顶部以强对比色带建立站点身份 | 使用近黑海军蓝状态条与朱红色信号点，建立“公开研究系统在线”的终端语义 | 原站 Logo、名称、日期栏与媒体图形 |
| 品牌横幅后接紧凑导航 | 使用暖白纸面背景、简洁品牌标志、研究方法/覆盖范围/终端入口导航 | 原站导航文案、会员功能和账户菜单 |
| 横向信息条承接资讯密度 | 使用不滚动的研究能力条，展示市场快照、评分、披露与资金结构模块 | 原站文章标题、图片缩略图和新闻流 |
| 高对比红色用于强调 | 将红色限定为 CTA、信号、研究强调与图表走势，不作为大面积页面底色 | 原站的红色视觉素材、背景和版式细节 |

## 自有品牌系统

标题页定义为“**机构化中国公开市场研究终端**”：暖白网格作为研究底稿，近黑海军蓝作为数据工作台，朱红色作为唯一的研究信号色。中文衬线大标题承担编辑化叙事；导航、指标、时间与证据标签采用紧凑技术字形。该系统与研究终端内既有的深色数据面板形成明确的首页—工作台层级。

## 信息架构

首页承接品牌与方法说明，主 CTA 固定导向 `/terminal`；终端的品牌区提供返回 `/` 的入口。首页不显示未验证行情或收益预测，只展示固定的产品机制说明和明确免责声明。研究终端继续负责 60 秒刷新、公开行情、来源链路与透明评分。
