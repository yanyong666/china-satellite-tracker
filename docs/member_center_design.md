# 会员中心：最小可用设计

## 产品范围

会员中心不是付费订阅或荐股服务。本期“会员”仅表示通过现有 OAuth 登录的研究用户，用于保存个人研究偏好；不新增收费、等级、收益承诺、私密行情或投资建议。

| 模块 | 已登录用户能力 | 未登录用户行为 |
| --- | --- | --- |
| 会员中心 | 查看账户名、登录邮箱、加入时间及已收藏标的 | 显示权益说明并提供安全登录入口 |
| 个人研究清单 | 收藏或移除首期股票池中的公开研究标的 | 点击收藏时进入既有 OAuth 登录流程 |
| 研究终端 | 从收藏标的直接进入公开终端 | 仍可完整浏览公开终端，不强制注册 |
| 品牌首页 | 显示“会员中心”或“登录以保存研究清单”入口 | 保持公开研究说明与终端入口 |

## 数据模型

新增 `user_saved_stocks` 表。每条记录仅保存系统内的 `userId`、首期股票池的 `stockId` 和创建时间；以 `(userId, stockId)` 唯一索引防止重复收藏。股票名称、行情、评分、新闻与披露不复制进用户表，仍由公开行情与股票池服务统一提供。

## 授权规则

所有收藏读写接口均使用 `protectedProcedure`。服务端从当前会话的 `ctx.user.id` 推导用户身份，不接受前端传入的用户 ID。未登录用户只能读取公开终端；登录入口统一调用现有 OAuth 的 `startLogin()`，不引入密码、支付信息或新的身份系统。
